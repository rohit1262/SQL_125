4.Find the largest order taken by each salesperson on each date. 


mysql> select s.snum,s.sname,o.odate,o.amt
    ->  from salespeople s
    ->  join orders o
    -> on s.snum = o.snum
    -> where amt =
    ->  (select max(o1.amt)
    ->   from orders o1
    ->  where o.snum = o1.snum
    ->  and o.odate = o1.odate);
