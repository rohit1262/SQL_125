19. Write a query that uses the EXISTS operator to extract all salespeople who have customers 
with a rating of 300. 
select s.snum,s.sname,s.city from salespeople s join customers c on s.snum=c.snum where c.rating = 300;-- this is without exists operator.

 SELECT s.snum, s.sname, s.city
     FROM salespeople s
     WHERE EXISTS (
        SELECT 1
         FROM customers c
         WHERE c.snum = s.snum
           AND c.rating = 300
     );

 select s.snum,s.sname,s.city from salespeople s where exists ( select 1 from customers c where c.snum = s.snum and c.rating = 300);
